# Smoke-test (före varje installation)

Kör manuellt på telefon + Fold innan APK installeras. Bocka av i slutrapporten.

## Kalender

- [ ] Helskärmsknappen (⛶) finns i headern och togglar minirad-läget i alla fyra lägen (Dag / Vecka / Månad / Agenda); valet sparas mellan omstarter
- [ ] Dag-vyn: alla lektioner synliga per kolumn (inte klumpade)
- [ ] Vecka / Månad / Agenda: skolan klumpad (`🏫 Skola …–…`)
- [ ] Månad: pills i cellerna + veckonummer + dagsheet över månaden
- [ ] Agenda: tidslinje med ✅-sysslor + sektionen "Sysslor utan tid"

## Sysslor & snabbadd

- [ ] Bocka syssla (konfetti + statistik uppdateras)
- [ ] Quick add `Test tis 17:00` → syns → radera
- [ ] Återkommande syssla: bocka idag → borta idag, tillbaka imorgon med nästa person i rotationen, EN loggpost

## Övrigt

- [ ] FAB och snackbar ligger HELT ovanför navet och går att trycka (testa i Kalender: Jag är upptagen-FAB + bocka en syssla och se snackbaren)
- [ ] Ställ systemklockan till 23:59 → 00:01: Hem och Kalender visar nya dagen utan omstart
- [ ] Rensa appens notiser i systeminställningarna → starta om appen → påminnelser återschemalagda
- [ ] AI-planeraren ger förslag med fungerande knappar
- [ ] Väderbadge syns på Hem
- [ ] Lågstimuli på/av påverkar alla lägen
- [ ] Sista posten i varje vy går att se HELT ovanför bottennavet
      (Dag/Vecka/Månad/Agenda/Sysslor/Hem/Inställningar)
